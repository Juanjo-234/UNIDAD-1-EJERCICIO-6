# UNIDAD-1-EJERCICIO-6
Resolución del ejercicio N°6 de programación 2.
Este programa administra la emisión de pasajes de avión.
Calcula el precio total a pagar según si el cliente lleva equipaje adicional o no. Si el pasajero lleva equipaje, le suma un recargo del 20% al precio final.
Al final muestra la información con el nombre del pasajero, el destino y el precio final del viaje.
